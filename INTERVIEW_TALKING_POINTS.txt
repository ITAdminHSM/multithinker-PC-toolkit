1. THE PROBLEM SOLVED
--------------------------------------------------------------------------------
In an enterprise or industrial manufacturing facility like Habib Sugar Mills, IT officers
manage hundreds of desktop workstations, scale terminals, weighing bridges, process
monitoring PCs, and administrative laptops. When an endpoint experiences network drops,
sluggish performance, or corrupt system files, traditional approaches often fail:
- Third-party utilities (CCleaner, third-party optimizers) violate cybersecurity policy
  and frequently introduce adware, privacy risks, or aggressive registry breakage.
- PowerShell scripts are blocked by Group Policy (Set-ExecutionPolicy Restricted).
- Python/Node scripts cannot run because runtime interpreters are strictly prohibited
  on client machines.
- Technicians waste 30-45 minutes per machine manually running individual CMD commands
  (ipconfig, ping, sfc, dism, cleanmgr) and copying logs by hand.

MUPT solves this by packaging the entire standard operating procedure into a single,
self-contained, 100% native Batch script that runs instantly from a technician's USB drive
on both Windows 10 and Windows 11 with zero prerequisites.

2. ARCHITECTURAL HIGHLIGHTS
--------------------------------------------------------------------------------
- Zero-Dependency Execution: Uses only native Windows Command binaries (ipconfig, netsh,
  reg, sfc, dism, sc, fsutil, w32tm, getmac).
- Deprecation Resilience (No WMIC): Microsoft permanently removed 'wmic.exe' in Windows 11
  24H2. MUPT extracts CPU, memory, and OS architecture directly from HKLM registry hives
  and 'systeminfo', guaranteeing future-proof execution.
- Safe Delay Engine: Replaces 'timeout' with 'ping 127.0.0.1 -n X >nul', preventing crash
  failures when scripts run under redirected I/O or background task runners.
- Input Sanitization & Anti-Injection: All user inputs for hostnames/IPs are piped
  through a regex filter that strictly strips/rejects shell metacharacters (&, |, <, >, ^, %).
- Controlled Delayed Expansion: Carefully avoids delayed expansion race conditions
  when handling file paths containing exclamation marks (!).

3. SAFETY DECISIONS & HONEST ENGINEERING
--------------------------------------------------------------------------------
- Zero Destructive Actions: Temp cleanup is confined strictly to %TEMP% and explicitly
  isolated cache directories. Never touches Documents, Downloads, or browser databases.
- Truthful RAM & Performance Management: Refuses to implement fake "RAM Cleaners".
  Instead, explains to users that modern Windows proactively caches memory, and forced
  memory flushing degrades system performance.
- Ethical Security Stance: Never displays or dumps saved Wi-Fi cleartext passwords.
  Network technicians should diagnose connectivity, not extract credentials.
- Least-Privilege Architecture: Diagnostics run under Standard User. Elevation is requested
  only when invoking kernel/system file operations (SFC, DISM, Winsock reset).

4. TESTING APPROACH (TDD & MOCK HARNESS)
--------------------------------------------------------------------------------
- Test Suite (MultiThinker_Tests.bat) implements 25 automated invariant checks.
- Operates in a non-destructive simulation harness ([SIMULATED]), ensuring no accidental
  deletions or configuration wipes happen during regression testing.
- Tracks real pass/fail counters and generates an automated timestamped audit log.

5. KNOWN LIMITATIONS (DISCLOSED HONESTLY)
--------------------------------------------------------------------------------
- Pure Batch scripts cannot compute true gigabit network throughput natively without
  compiling socket binaries; therefore, MUPT transparently integrates with certified browser
  speedtest engines (Cloudflare / Ookla) while handling ICMP latency locally.
- Hardware temperature telemetry (CPU/GPU thermals) requires kernel ring-0 sensors not
  exposed to basic command-line utilities without vendor-specific drivers.

Q1: "Why build a maintenance toolkit in Batch rather than PowerShell or Python?"
A1: "In a corporate manufacturing environment like Habib Sugar Mills, security policy
     strictly restricts executing PowerShell scripts under default Restricted ExecutionPolicy,
     and installing Python runtime environments on 500+ endpoints is impractical and creates
     an unmanaged attack surface. A pure Batch script is universal: it executes instantly on
     factory Windows 10 and 11 workstations without altering security policies, opening
     firewall ports, or installing third-party runtimes."

Q2: "How do you handle the deprecation of WMIC on modern Windows 11 builds?"
A2: "In Windows 11 22H2 and 24H2, Microsoft deprecated and removed wmic.exe. If an IT script
     relies on 'wmic cpu get name' or 'wmic memorychip', it crashes immediately. In MUPT,
     I architected all hardware queries using registry queries against
     'HKLM\HARDWARE\DESCRIPTION\System\CentralProcessor\0' and systeminfo parsers. This
     demonstrates my proactive awareness of Windows operating system release lifecycles."

Q3: "How do you protect against command injection when accepting user input in CMD?"
A3: "In Batch scripts, accepting a raw hostname like '8.8.8.8 & del C:\test.txt' can lead to
     disastrous command injection. In MUPT, I built a dedicated subroutine, :SUB_VALIDATE_HOSTNAME,
     that pipes the user's string through findstr /R matching dangerous shell metacharacters:
     ampersands, pipes, carets, redirects, and percent signs. If any forbidden character is
     detected, the script halts execution with an errorlevel 1 and logs an alert."

Q4: "What is your approach to PC cleaning, and why do many commercial tools cause harm?"
A4: "Many commercial utilities claim to 'speed up' PCs by deleting registry entries and wiping
     RAM. In enterprise support, registry cleaning is dangerous and produces zero performance
     gains because modern Windows registry is a fast memory-mapped hive. Furthermore, modern
     Windows uses free RAM for SuperFetch and Standby caching. MUPT takes an ethical, safe-by-
     default stance: it purges disposable scratch files from %TEMP%, bypasses in-use locked
     handles without crashing, and launches native Windows Disk Cleanup (cleanmgr.exe) for
     deep system servicing."

Q5: "How does this project reflect your daily work at Habib Sugar Mills Ltd?"
A5: "At Habib Sugar Mills, we operate in high-demand, 24/7 industrial conditions where downtime
     directly impacts production and weighing logistics. As an IT Officer, I cannot afford
     unreliable tools or guesswork. MUPT represents the exact disciplined mindset I bring to
